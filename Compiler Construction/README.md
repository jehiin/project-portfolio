# Compiler Construction

Rust compiler projects that progressively add control flow, procedures, datatypes, analysis, register allocation, and optimization.

## Projects

| Project | Summary |
|---|---|
| [Straight-Line Code Compiler](Straight-Line%20Code%20Compiler.md) | Implemented compiler support for straight-line programs and translation through the initial intermediate representations. |
| [Control-Flow Compilation](Control-Flow%20Compilation.md) | Extended the compiler with conditionals, loops, labels, jumps, and control-flow-sensitive translation. |
| [Procedure Compilation](Procedure%20Compilation.md) | Added procedure calls, calling conventions, argument passing, returns, and stack-aware code generation. |
| [Datatype and Heap Support](Datatype%20and%20Heap%20Support.md) | Added richer datatypes, heap-allocated values, runtime checks, and type-aware compiler behavior. |
| [Compiler Optimization](Compiler%20Optimization.md) | Implemented liveness analysis, register allocation, and optimization passes while preserving program semantics. |
