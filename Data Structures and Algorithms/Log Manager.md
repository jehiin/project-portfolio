# Log Manager

## Overview

Developed an interactive log-analysis engine that ingests, orders, indexes, searches, and curates large timestamped datasets.  
Built category and keyword hash indexes alongside binary-searchable timestamp ordering to support fast range, exact-match, and multi-term queries.  
Implemented a mutable excerpt list with append, delete, move, sort, and clear operations, then tested command sequences and duplicate-heavy edge cases.

## What This Demonstrates

- Hash-based indexing
- Binary search
- Query processing
