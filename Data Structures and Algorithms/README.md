# Data Structures and Algorithms

Algorithm-intensive C++ projects using graph search, priority queues, indexing, minimum spanning trees, and branch-and-bound optimization.

## Projects

| Project | Summary |
|---|---|
| [Statistics Foundations](Statistics%20Foundations.md) | Applied core C++ data processing and statistical calculations as an algorithms-course foundation project. |
| [Letterman Word Transformation](Letterman%20Word%20Transformation.md) | Solved word-transformation problems using breadth-first and depth-first search with configurable mutation rules. |
| [Priority Queue Implementations](Priority%20Queue%20Implementations.md) | Implemented multiple priority-queue variants, including heap-based and pairing-heap structures, behind a common interface. |
| [Stock Market Simulator](Stock%20Market%20Simulator.md) | Simulated order matching with priority queues and supported running medians, trader summaries, and time-traveler analysis. |
| [Log Manager](Log%20Manager.md) | Built an indexed log-search system supporting timestamp, category, keyword, and excerpt-list operations. |
| [Drone Delivery Optimization](Drone%20Delivery%20Optimization.md) | Implemented minimum-spanning-tree, heuristic traveling-salesperson, and optimal branch-and-bound routing modes. |
