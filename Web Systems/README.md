# Web Systems

Full-stack and distributed web projects using templating, Flask, SQL, React, REST APIs, MapReduce, indexing, and ranked retrieval.

## Projects

| Project | Summary |
|---|---|
| [Templated Static Site Generator](Templated%20Static%20Site%20Generator.md) | Built a Python static-site generator that renders reusable Jinja templates into a multi-page social-media interface. |
| [Server-Side Social Media Application](Server-Side%20Social%20Media%20Application.md) | Implemented a Flask application with authentication, sessions, SQL-backed CRUD operations, uploads, and server-rendered pages. |
| [React Social Media Interface](React%20Social%20Media%20Interface.md) | Added a React and JSX client that consumes REST APIs, performs asynchronous updates, and supports dynamic post interactions. |
| [Distributed MapReduce Framework](Distributed%20MapReduce%20Framework.md) | Built a Python Manager-Worker framework using processes, threads, TCP/UDP communication, task coordination, fault recovery, logging, and tests. |
| [Search Engine and Information Retrieval](Search%20Engine%20and%20Information%20Retrieval.md) | Built a service-oriented search engine with a segmented inverted index, parallel indexing, tf-idf, PageRank, JSON APIs, and ranked query results. |
