# Templated Static Site Generator

## Overview

Built a Python static-site generator that converts structured JSON data and reusable Jinja templates into a complete multi-page social-media site.  
Created shared layouts for feeds, user profiles, follower/following views, and individual posts while preserving consistent navigation and asset paths.  
Packaged the generator as a command-line program and validated both rendered HTML structure and visual behavior with automated tests.

## What This Demonstrates

- Template rendering
- Static-site generation
- Reusable page structure

## Technologies

Python, Jinja, HTML, CSS
