# Search Engine and Information Retrieval

## Overview

Built a service-oriented search engine that turns a web corpus into ranked results through a multi-stage MapReduce indexing pipeline.  
Computed document normalization, tf-idf weights, PageRank signals, stop-word filtering, and a segmented inverted index served through parallel JSON API instances.  
Integrated the index tier with a Flask search interface that merges results, applies user-controlled ranking weights, and returns concise document summaries.

## What This Demonstrates

- Inverted indexing
- Ranking algorithms
- Service-oriented integration

## Technologies

Python, Flask, MapReduce, JSON, information retrieval
