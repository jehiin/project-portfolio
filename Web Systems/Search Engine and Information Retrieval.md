# Search Engine and Information Retrieval

## Overview

Built a service-oriented search engine with a segmented inverted index, parallel indexing, tf-idf, PageRank, JSON APIs, and ranked query results.

## What This Demonstrates

- Inverted indexing
- Ranking algorithms
- Service-oriented integration

## Technologies

Python, Flask, MapReduce, JSON, information retrieval
