# Digital Logic Design

Verilog and FPGA projects covering combinational logic, sequential circuits, finite-state machines, arithmetic datapaths, and verification.

## Projects

| Project | Summary |
|---|---|
| [Selector](Selector.md) | Designed a parameterized selector circuit and top-level FPGA integration in Verilog. |
| [Robbie Robot Controller](Robbie%20Robot%20Controller.md) | Implemented robot decision and action logic from input conditions using modular Verilog components. |
| [Renee Robot Controller](Renee%20Robot%20Controller.md) | Built a second robot-control design using unsigned comparison and action-selection logic. |
| [Combinational Calculator](Combinational%20Calculator.md) | Built a combinational calculator from full adders, add/subtract logic, and seven-segment display conversion. |
| [Up-Down Counter](Up-Down%20Counter.md) | Implemented and tested sequential up/down counter designs with clocked state updates and control inputs. |
| [Traffic Light Controller](Traffic%20Light%20Controller.md) | Designed a clocked traffic-light controller with finite-state behavior, timing control, and display output. |
| [Sequential Calculator](Sequential%20Calculator.md) | Built a four-function sequential calculator that coordinates arithmetic operations across a clocked datapath and control flow. |
