# Programming and Data Structures

Object-oriented C++ projects emphasizing abstraction, dynamic memory, reusable data structures, unit testing, and debugging.

## Projects

| Project | Summary |
|---|---|
| [Statistics](Statistics.md) | Implemented a statistics library and command-line data analysis workflow for tabular datasets. |
| [Image Processing](Image%20Processing.md) | Built matrix and image abstractions and used them to implement content-aware image resizing. |
| [Euchre](Euchre.md) | Developed a complete Euchre card-game simulator with player strategies, dealing, bidding, trick play, scoring, and deterministic tests. |
| [Machine Learning Text Classifier](Machine%20Learning%20Text%20Classifier.md) | Implemented a text-classification program that learns word-label relationships and predicts labels for unseen posts. |
| [Text Editor](Text%20Editor.md) | Implemented a text-buffer abstraction backed by a custom doubly linked list with cursor, row, and column tracking. |
| [Binary Search Tree and Map](Binary%20Search%20Tree%20and%20Map.md) | Built templated binary-search-tree and associative-map abstractions with traversal, lookup, insertion, and ordering behavior. |
