# Relational Database Foundations

## Overview

Designed an Oracle relational schema for a social-network dataset spanning users, friendships, cities, education, messages, events, albums, photos, and tags.  
Encoded primary and foreign keys, uniqueness and domain constraints, deferred circular references, sequences, triggers, and reusable views.  
Built repeatable create, load, and teardown scripts that preserve relational integrity across a highly connected data model.

## What This Demonstrates

- Relational modeling
- Query formulation
- Constraint-aware design
