# MongoDB Queries

## Overview

Implemented a MongoDB analytics suite for document-based social-network data using JavaScript queries and aggregation pipelines.  
Unwound embedded friendship arrays, materialized derived collections, grouped users by city and birth month, and computed relationship and demographic results.  
Used matching, projection, grouping, sorting, lookup-style transformations, and collection writes to solve seven distinct data-processing tasks.

## What This Demonstrates

- Document modeling
- Aggregation pipelines
- NoSQL query design
