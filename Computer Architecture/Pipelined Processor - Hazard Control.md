# Pipelined Processor - Hazard Control

## Overview

Extended the pipelined CPU with dependency-aware control for data, control, and structural hazards.  
Implemented stalling, forwarding, and pipeline-squashing behavior so overlapping instructions preserve sequential program semantics.  
Built targeted assembly tests for edge cases and verified cycle-by-cycle behavior through regression runs and waveform analysis.

## What This Demonstrates

- Hazard detection
- Pipeline control
- Directed testing

## Technologies

SystemVerilog, Synopsys VCS
