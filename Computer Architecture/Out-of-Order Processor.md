# Out-of-Order Processor

## Overview

Collaborated on a SystemVerilog processor that schedules independent micro-operations beyond program order while preserving correct retirement behavior.  
Integrated fetch/decode stages, a micro-operation queue, dependency checking, execution units, register state, memory management, instruction caching, and gshare branch prediction.  
Measured CPI and benchmark behavior with automated scripts, then used directed tests, pipeline traces, waveforms, and synthesis checks to validate the complete design.

## What This Demonstrates

- Out-of-order scheduling
- Dependency tracking
- Caches and branch prediction

## Technologies

SystemVerilog, Synopsys VCS, Design Compiler
