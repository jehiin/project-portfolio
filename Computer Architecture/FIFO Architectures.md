# FIFO Architectures

## Overview

Built parameterized shift-register and circular-buffer FIFOs with explicit enqueue, dequeue, full, and empty behavior.  
Designed the circular implementation around read/write pointers and occupancy tracking so storage remains fixed while data movement is minimized.  
Used simulation and synthesis results to verify ordering guarantees and compare the hardware cost of two distinct queue architectures.

## What This Demonstrates

- Sequential storage
- Control logic
- Synthesis-aware design
