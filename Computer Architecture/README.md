# Computer Architecture

SystemVerilog processor-design work covering synthesis, FIFOs, datapaths, pipelines, caches, branch prediction, and out-of-order execution.

## Projects

| Project | Summary |
|---|---|
| [Parameterized Minimum Circuits](Parameterized%20Minimum%20Circuits.md) | Designed flat and hierarchical minimum-selection circuits and compared implementation structure, timing, and synthesis behavior. |
| [FIFO Architectures](FIFO%20Architectures.md) | Implemented and compared shift-register and circular FIFO architectures with parameterized depth and width. |
| [Processor Datapath Exercise](Processor%20Datapath%20Exercise.md) | Implemented a processor datapath exercise and verified instruction behavior with supplied programs and test infrastructure. |
| [Pipelined Processor - Stage Integration](Pipelined%20Processor%20-%20Stage%20Integration.md) | Developed and integrated a staged processor design with fetch, computation, and memory/retirement structure. |
| [Pipelined Processor - Hazard Control](Pipelined%20Processor%20-%20Hazard%20Control.md) | Extended the processor pipeline with control needed for correct instruction flow under dependencies and hazards. |
| [Pipelined Processor - Performance Features](Pipelined%20Processor%20-%20Performance%20Features.md) | Enhanced the pipelined processor and evaluated functional behavior, timing, and synthesis results. |
| [Pipelined Processor - Final Integration](Pipelined%20Processor%20-%20Final%20Integration.md) | Completed an integrated pipelined processor implementation and validated it with assembly programs, testbenches, and waveforms. |
| [Out-of-Order Processor](Out-of-Order%20Processor.md) | Collaborated on a processor with fetch and decode stages, a micro-operation queue, dependency checking, execution units, caching, and branch prediction. |
