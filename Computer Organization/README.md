# Computer Organization

Low-level systems projects spanning assembly, translation, linking, processor simulation, pipelining, hazards, and caches.

## Projects

| Project | Summary |
|---|---|
| [Multiplication in Assembly](Multiplication%20in%20Assembly.md) | Wrote an LC-2K assembly program that performs multiplication using low-level control flow and bit-level reasoning. |
| [LC-2K Assembler](LC-2K%20Assembler.md) | Implemented an assembler that translates LC-2K assembly instructions and labels into machine code. |
| [LC-2K Instruction Simulator](LC-2K%20Instruction%20Simulator.md) | Built an instruction-level simulator that executes LC-2K machine code and reports architectural state. |
| [Advanced LC-2K Assembler](Advanced%20LC-2K%20Assembler.md) | Extended assembly translation to emit relocatable object files with text, data, symbols, and relocation metadata. |
| [LC-2K Linker](LC-2K%20Linker.md) | Implemented a linker that combines object files, resolves symbols, applies relocations, and emits a final executable image. |
| [LC-2K Pipeline Simulator](LC-2K%20Pipeline%20Simulator.md) | Built a cycle-accurate pipelined processor simulator with forwarding, stalls, branch handling, and hazard control. |
| [Cache Simulator](Cache%20Simulator.md) | Integrated a configurable cache model with a processor simulator and tracked cache hits, misses, dirty state, and memory transfers. |
